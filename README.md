# 还有一格电

原创现实主义小说《还有一格电》的静态阅读页：在线按章阅读、Markdown 全文下载，另附可下载的视觉小说离线包。

## 说明

- 本仓库为可公开的静态运行/构建产物，不包含私有源码、测试与评审素材。
- 仓库未附开源许可，代码、文案与素材未授予额外复用许可；第三方引擎与字体按其自带许可使用。

## 本地运行

静态站点，任意静态服务器即可：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```
